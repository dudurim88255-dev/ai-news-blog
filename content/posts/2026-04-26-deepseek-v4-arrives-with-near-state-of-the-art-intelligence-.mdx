# DeepSeek-V4 가격 완전 분석: GPT-5.5의 1/7 가격으로 비슷한 성능?

2026년 4월, AI 업계가 다시 한번 뒤흔들렸다. DeepSeek이 V4 모델을 출시하면서 프리미엄 AI API 시장의 가격 구조 자체를 흔들어 놓았기 때문이다. 2025년 1월 R1 모델이 등장했을 때의 충격—당시 미국 주요 AI 기업들의 주가를 일제히 끌어내렸던 바로 그 순간—이 재현되고 있다는 평가가 나온다. GPT-5.5나 [Claude](https://claude.ai) Opus 4.7을 쓰고 있거나, 대규모 AI 인프라 비용을 고민하는 개발자와 기업 담당자라면 이 가격표를 반드시 살펴봐야 한다. 단순 비교 기준으로 DeepSeek-V4-Pro의 API 비용은 GPT-5.5의 약 7분의 1 수준이다. 이 숫자가 실제로 무엇을 의미하는지, 그리고 어떤 상황에서 선택해야 하는지 짚어본다.

---

## 요금제 한눈에 보기

DeepSeek-V4는 크게 두 가지 API 티어로 제공된다. **V4-Pro**와 **V4-Flash**다. 공식 발표에 따르면 모델 전체는 MIT 라이선스 오픈소스로 공개되어 있으며, Hugging Face에서 무료로 내려받을 수 있다. 상업적 이용도 가능한 라이선스다.

API 사용 기준 공식 가격은 다음과 같다.

**DeepSeek-V4-Pro**
- 입력 토큰 (캐시 미스): $1.74 / 100만 토큰
- 출력 토큰: $3.48 / 100만 토큰
- 캐시 히트 시 입력: $0.145 / 100만 토큰

**DeepSeek-V4-Flash**
- 입력 토큰 (캐시 미스): $0.14 / 100만 토큰
- 출력 토큰: $0.28 / 100만 토큰
- 캐시 히트 시 입력가 기준 합산: 약 $0.308

원화로 환산하면 (2026년 4월 기준 약 1,380원/달러 적용 시), V4-Pro의 입력+출력 합산 단순 비교 비용 $5.22는 약 **7,200원 / 100만 토큰 쌍** 수준이다. V4-Flash는 같은 기준으로 약 **580원**이다.

이 모델의 파라미터 수는 공식 발표 기준 **1.6조(1.6 trillion) 파라미터의 Mixture-of-Experts(MoE) 구조**다. V3 시리즈 출시 후 484일 만에 나온 후속작으로, DeepSeek AI 연구원 Deli Chen은 X(트위터)에서 이를 "공들여 만든 작품(labor of love)"이라고 표현했다.

한국어 지원 여부와 국내 정식 출시 일정은 현재 공개된 정보가 없다. API는 글로벌 공개 상태이므로 국내 개발자도 DeepSeek API 문서를 통해 직접 접근 가능하다. 다만 한국어 특화 성능에 대한 공식 벤치마크는 발표되지 않은 상태다.

## 무료 플랜으로 실제로 뭘 할 수 있나?

DeepSeek-V4의 모델 가중치 자체는 MIT 라이선스로 Hugging Face에 무료 공개되어 있다. 이는 상업적 사용도 허용되는 조건이다.

즉, 자체 서버나 클라우드 인프라가 있는 개발자나 기업이라면 모델을 직접 내려받아 운영하는 것이 이론적으로 가능하다. 다만 1.6조 파라미터 MoE 모델을 실제로 자체 인프라에서 돌리려면 상당한 GPU 자원이 필요하다는 점은 현실적 제약으로 작용한다. 구체적인 최소 하드웨어 요구사양은 현재 공식 발표에서 확인되지 않는다.

API를 통한 무료 사용 티어가 있는지 여부도 현재 공개된 정보에는 명시되어 있지 않다. 기존 DeepSeek API는 일정 무료 크레딧을 제공한 전례가 있으나, V4에 대해 동일한 조건이 적용되는지는 공식 문서에서 확인이 필요하다.

결론적으로 "완전 무료"로 V4를 사용하려면 자체 호스팅 경로를 택해야 하며, 이는 기술적 역량과 인프라 비용이 전제된다. API를 쓰는 일반적인 사용 방식에서는 유료 과금이 발생한다.

## 유료 플랜, 돈 값 하나? (원화 환산 포함)

핵심 질문은 결국 이것이다. 이 가격에 성능이 따라오는가.

VentureBeat 원문 보도에 따르면, DeepSeek-V4-Pro-Max는 최신 클로즈드 프론티어 모델들과 비교했을 때 **대부분의 벤치마크에서 GPT-5.5와 Claude Opus 4.7에 미치지 못하지만, 일부 항목에서는 근접하거나 앞선다**.

공개된 주요 벤치마크 수치는 다음과 같다.

| 벤치마크 | DeepSeek-V4-Pro-Max | GPT-5.5 | Claude Opus 4.7 |
|---|---|---|---|
| GPQA Diamond | 90.1% | 93.6% | 94.2% |
| Humanity's Last Exam (도구 없음) | 37.7% | 41.4% | 46.9% |
| Humanity's Last Exam (도구 활용) | 48.2% | 52.2% | 54.7% |
| Terminal-Bench 2.0 | 67.9% | 82.7% | 69.4% |
| SWE-Bench Pro | 55.4% | 58.6% | 64.3% |
| BrowseComp | 83.4% | 84.4% | 79.3% |

BrowseComp(에이전트 웹 브라우징 능력 측정)에서는 DeepSeek이 83.4%로 GPT-5.5의 84.4%에 불과 1%포인트 차이로 따라붙고, Claude Opus 4.7의 79.3%는 앞선다. 반면 Terminal-Bench 2.0에서는 DeepSeek 67.9% 대 GPT-5.5 82.7%로 차이가 크다.

다시 말해, 용도에 따라 성능 격차의 체감이 크게 달라진다. 웹 브라우징 기반 에이전트 작업이라면 가격 대비 효율이 높고, 복잡한 터미널 작업이나 과학적 추론에서는 아직 프리미엄 모델과 간극이 존재한다.

원화로 환산한 비용을 실제 업무 스케일로 계산해보면:

- **월 1억 토큰 처리 (입출력 각 5000만 토큰 기준)**
  - DeepSeek-V4-Pro: 약 37만 원 ($262)
  - GPT-5.5: 약 245만 원 ($1,750)
  - Claude Opus 4.7: 약 210만 원 ($1,500)

대규모 인퍼런스를 돌리는 기업 입장에서는 이 차이가 수천만 원에서 수억 원 단위의 연간 비용 절감으로 이어질 수 있다.

## 경쟁 서비스와 가격 비교

원문에 공개된 비교 테이블을 기준으로 주요 모델들의 가격을 정리하면 다음과 같다. (단위: $USD / 100만 토큰, 입력+출력 단순 합산 기준)

| 모델 | 입력 | 출력 | 합산 |
|---|---|---|---|
| Grok 4.1 Fast | $0.20 | $0.50 | $0.70 |
| MiniMax M2.7 | $0.30 | $1.20 | $1.50 |
| [Gemini](https://gemini.google.com) 3 Flash | $0.50 | $3.00 | $3.50 |
| Kimi-K2.5 | $0.60 | $3.00 | $3.60 |
| **DeepSeek-V4-Pro** | **$1.74** | **$3.48** | **$5.22** |

이 표에서 몇 가지 주목할 점이 있다.

첫째, DeepSeek-V4-Pro가 고성능 모델 중 가장 저렴한 편이긴 하지만, 가격 자체만 놓고 보면 Grok 4.1 Fast($0.70), MiniMax M2.7($1.50), Gemini 3 Flash($3.50) 같은 경쟁 모델들이 더 저렴하다. 이 모델들과의 성능 비교는 원문에 직접 제시된 벤치마크가 없어 판단을 유보한다.

둘째, GPT-5.4 Pro는 합산 $210로, DeepSeek-V4-Pro 대비 약 40배 비싸다. 이 두 모델의 성능 격차가 40배를 정당화하는지는 사용 목적에 따라 판단이 갈릴 것이다.

셋째, 캐시 히트 조건이 적용되면 DeepSeek-V4-Pro의 가격 경쟁력은 더욱 커진다. 캐시 적용 시 GPT-5.5 대비 약 1/10 수준으로 떨어진다.

## 어떤 플랜을 선택해야 할까? (상황별 추천)

**개인 개발자 / 소규모 프로젝트**

비용 제약이 크고, 최고 성능이 절대적으로 필요하지 않다면 DeepSeek-V4-Flash가 현실적인 선택이다. 합산 $0.42로 GPT-5.5($35.00)의 약 98% 저렴하다. 다만 "성능이 크게 떨어진다"는 점은 원문에 명시되어 있다. 간단한 텍스트 처리, 요약, 분류 작업에는 충분할 수 있다.

**중간 규모 SaaS / 스타트업**

BrowseComp이나 코드 관련 작업 비중이 높다면 DeepSeek-V4-Pro가 GPT-5.5 대비 가격 대비 성능 측면에서 검토할 만하다. BrowseComp 기준 1%포인트 차이를 감안할 때, 웹 에이전트 기반 서비스라면 비용 절감 효과가 크다.

**엔터프라이즈 / 대규모 인퍼런스**

월 수억 토큰 이상을 처리하는 조직이라면 DeepSeek-V4-Pro로 전환 시 연간 비용 차이가 매우 크다. 다만 데이터 보안, 규정 준수(컴플라이언스), 중국 기업 서비스 이용에 따른 내부 정책 등을 함께 검토해야 한다. 이 부분은 기술 외적 의사결정 요소다.

**최고 정확도가 필요한 작업**

GPQA Diamond, Humanity's Last Exam 등 고난도 추론 작업에서 Claude Opus 4.7이 DeepSeek-V4-Pro-Max를 앞선다는 점은 벤치마크 수치로 확인된다. 의료, 법률, 고급 과학 연구 등 오류 비용이 높은 도메인에서는 프리미엄 모델의 우위가 여전히 유효하다.

**자체 호스팅을 고려하는 기업**

MIT 라이선스 오픈소스 특성상 자체 GPU 인프라를 갖춘 기업은 API 비용 없이 운영이 가능하다. 초기 인프라 구축 비용과 운영 인건비를 감안한 총소유비용(TCO) 계산이 필요하다.

## 더 저렴하게 쓰는 꿀팁

공식 발표 기준으로 확인된 비용 절감 방법은 다음과 같다.

**캐시 히트 활용**이 가장 효과적이다. DeepSeek-V4-Pro의 캐시 히트 시 입력 단가는 $0.145로, 캐시 미스($1.74)의 약 1/12 수준이다. 반복적으로 동일하거나 유사한 프롬프트 앞부분(시스템 프롬프트 등)을 사용하는 애플리케이션이라면 캐시 구조를 적극적으로 설계하는 것이 유리하다. 같은 비교 조건에서 DeepSeek-V4-Pro는 GPT-5.5 대비 약 1/7(캐시 미스)에서 약 1/10(캐시 히트)으로 비용이 낮아진다.

**모델 티어 조합** 전략도 고려할 수 있다. 모든 요청을 V4-Pro로 처리하는 대신, 단순 작업은 V4-Flash($0.42 기준)로 라우팅하고, 복잡한 추론이 필요한 경우에만 V4-Pro를 사용하는 방식이다. 이 경우 평균 단가를 크게 낮출 수 있다.

**자체 호스팅**은 대규모 사용량에서 API 비용 자체를 제거할 수 있는 방법이다. 모델 가중치가 MIT 라이선스로 공개되어 있으므로 기술 역량이 있는 팀은 이 경로를 검토할 수 있다. 다만 GPU 인프라 비용과 운영 비용이 수반된다는 점을 감안해야 한다.

할인 코드나 프로모션 관련 정보는 현재 공식 발표에 포함되어 있지 않다. 연간 구독 할인 여부도 확인되지 않는다. API 과금 구조는 사용량 기반(pay-per-use)으로만 현재 공개되어 있다.

---

정리하자면, DeepSeek-V4의 등장은 프리미엄 AI API 시장의 가격 방어선을 흔들고 있다. GPT-5.5나 Claude Opus 4.7이 성능 면에서 여전히 앞서는 벤치마크가 다수 존재하지만, 그 성능 차이를 가격 차이(약 6~7배)로 정당화할 수 있는지는 사용 목적에 따라 크게 달라진다. 대규모 인퍼런스를 운영하는 기업이나 비용에 민감한 개발자라면 DeepSeek-V4-Pro는 진지하게 검토할 만한 선택지다. 다만 데이터 주권, 보안 정책, 한국어 성능 등 기술 외적 요소도 함께 고려해야 할 것이다.
