# DeepSeek-V4 가격 완전 분석: GPT-5.5·[Claude](https://claude.ai) Opus 4.7보다 1/6 저렴한 이유

2026년 4월, AI 업계에서 다시 한 번 "DeepSeek 모멘트"가 터졌다. DeepSeek-V4가 공개되면서 개발자와 기업 담당자들이 API 가격표를 다시 꺼내 들고 있다. 핵심 질문은 하나다. "지금 쓰는 유료 AI API, 계속 써야 하나?" 이 글에서는 DeepSeek-V4의 실제 가격 구조를 낱낱이 뜯어보고, 한국 개발자·기업 관점에서 어떤 선택이 합리적인지 따져본다.

---

## 요금제 한눈에 보기

공식 발표에 따르면 DeepSeek-V4는 크게 두 가지 API 티어로 제공된다.

**DeepSeek-V4-Pro**
- 입력(캐시 미스): **$1.74 / 100만 토큰**
- 출력: **$3.48 / 100만 토큰**
- 캐시 히트 시 입력: **$0.145 / 100만 토큰**

**DeepSeek-V4-Flash**
- 입력(캐시 미스): **$0.14 / 100만 토큰**
- 출력: **$0.28 / 100만 토큰**
- 캐시 히트 시 입력 기준 합산: **$0.308**

라이선스는 MIT 오픈소스로 상업적 사용이 가능하다. 모델 가중치는 Hugging Face에서 무료로 내려받을 수 있으며, API는 DeepSeek 공식 플랫폼을 통해 별도 과금된다.

파라미터 규모는 1.6조(1.6 trillion) 개의 혼합 전문가(Mixture-of-Experts, MoE) 아키텍처다. V3 출시로부터 484일 만에 공개된 모델이며, DeepSeek AI 연구원 Deli Chen은 X(구 트위터)에서 이 모델을 "공들여 만든 작품(labor of love)"이라고 표현했다.

한국에서 API를 사용할 경우, 2026년 4월 기준 환율(약 1,380원/달러 적용 시) 단순 환산하면:

- V4-Pro 입력(캐시 미스) 100만 토큰당 약 **2,401원**
- V4-Pro 출력 100만 토큰당 약 **4,802원**
- V4-Flash 입력 100만 토큰당 약 **193원**
- V4-Flash 출력 100만 토큰당 약 **386원**

단, 한국어 지원 수준이나 국내 전용 서비스 출시 여부는 현재 공식 발표된 바 없다. API는 글로벌 공통으로 제공된다.

## 무료 플랜으로 실제로 뭘 할 수 있나?

DeepSeek-V4의 모델 가중치 자체는 MIT 라이선스로 무료 공개되어 있다. 즉, 자체 서버나 클라우드 인프라를 보유한 팀이라면 직접 배포해 무료로 사용할 수 있다.

다만 이 부분은 조건이 붙는다.

첫째, 1.6조 파라미터 MoE 모델은 그 자체로 상당한 GPU 메모리와 연산 자원을 요구한다. 개인 개발자가 로컬에서 돌리는 것은 현실적으로 어렵고, 기업 단위의 인프라 투자가 전제된다.

둘째, API 형태로 사용하는 경우는 무료가 아니다. DeepSeek 공식 API는 위에 기재된 가격대로 과금된다.

셋째, DeepSeek 웹 플랫폼(chat.deepseek.com)에서 일반 사용자 대상 무료 채팅 서비스는 별도로 운영 중이나, 이는 API 접근과 다른 레이어다.

결론적으로, "무료 플랜"이라는 개념은 전통적인 SaaS 방식의 무료 티어가 아니라 "오픈소스 가중치 공개"의 형태다. 자체 인프라를 갖춘 팀에게는 의미 있는 무료 활용 경로지만, API 기반으로 바로 쓰려는 팀에게는 유료 과금이 발생한다.

## 유료 플랜, 돈 값 하나? (원화 환산 포함)

VentureBeat 보도에 따르면, 100만 입력 + 100만 출력 토큰 기준 단순 비교 시 DeepSeek-V4-Pro는 **$5.22**다.

같은 기준으로 경쟁 모델을 나열하면:

- **GPT-5.5**: 입력 $5.00 + 출력 $30.00 = **합산 $35.00**
- **Claude Opus 4.7**: 입력 $5.00 + 출력 $25.00 = **합산 $30.00**

DeepSeek-V4-Pro는 캐시 미스 기준으로 GPT-5.5 대비 약 **1/7 수준**, Claude Opus 4.7 대비 약 **1/6 수준**이다.

캐시 히트 적용 시 입력 비용이 $0.145로 떨어지면서 합산이 $3.625로 내려간다. 이 경우 GPT-5.5 대비 약 **1/10**, Claude Opus 4.7 대비 약 **1/8** 수준으로 차이가 더 벌어진다.

원화 환산(약 1,380원/달러 기준):

| 모델 | 합산 비용(100만 입력+출력) | 원화 환산 |
|------|--------------------------|----------|
| DeepSeek-V4-Flash | $0.42 | 약 580원 |
| DeepSeek-V4-Pro (캐시 히트) | $3.625 | 약 5,003원 |
| DeepSeek-V4-Pro | $5.22 | 약 7,204원 |
| Claude Opus 4.7 | $30.00 | 약 41,400원 |
| GPT-5.5 | $35.00 | 약 48,300원 |

대규모 추론 워크로드를 운영하는 기업 입장에서는 이 차이가 월 수천만 원, 연간 수억 원 규모의 비용 절감으로 이어질 수 있다.

단, 성능 차이도 분명히 존재한다. VentureBeat 보도에 따르면 DeepSeek-V4-Pro-Max는 최신 폐쇄형 모델들과 비교했을 때 대부분의 벤치마크에서 GPT-5.5와 Claude Opus 4.7에 뒤처진다.

벤치마크 수치를 보면:
- **GPQA Diamond**: DeepSeek 90.1% / GPT-5.5 93.6% / Claude Opus 4.7 94.2%
- **Humanity's Last Exam(도구 없음)**: DeepSeek 37.7% / GPT-5.5 41.4% / Claude Opus 4.7 46.9%
- **Terminal-Bench 2.0**: DeepSeek 67.9% / GPT-5.5 82.7% / Claude Opus 4.7 69.4%
- **SWE-Bench Pro**: DeepSeek 55.4% / GPT-5.5 58.6% / Claude Opus 4.7 64.3%
- **BrowseComp**: DeepSeek 83.4% / GPT-5.5 84.4% / Claude Opus 4.7 79.3%

BrowseComp에서는 DeepSeek가 Claude Opus 4.7을 앞섰고 GPT-5.5와 불과 1%p 차이다. 하지만 Terminal-Bench 2.0에서는 GPT-5.5와 14.8%p 격차가 난다. 태스크에 따라 성능 격차의 폭이 다르다.

중요한 맥락이 있다. DeepSeek 자체 벤치마크 비교표는 GPT-5.4, Claude Opus 4.6 등 구버전과의 비교를 담고 있으며, 최신 GPT-5.5·Opus 4.7과의 직접 비교는 제한적이다. 성능 평가 시 이 점을 감안해야 한다.

주목할 점은 DeepSeek-V4-Flash($0.42)가 사실상 초저가 구간에 속한다는 것이다. VentureBeat에 따르면 Flash 모델은 GPT-5.5 대비 98% 이상 저렴하지만, 성능 하락도 동반된다고 명시되어 있다.

중국 AI 모델들이 가격 경쟁에서 상당히 공격적인 포지셔닝을 하고 있음도 눈에 띈다. GLM-5, Kimi-K2.5, MiniMax M2.7 등 중국 업체들이 모두 $5 미만 구간에 밀집해 있다. DeepSeek-V4-Pro는 이 무리 중에서 성능 포지셔닝이 상대적으로 높은 편이다.

## 어떤 플랜을 선택해야 할까? (상황별 추천)

**대규모 추론 워크로드가 있는 기업**

월 수십억 토큰 이상을 처리하는 기업이라면 DeepSeek-V4-Pro의 가격 메리트가 뚜렷하다. 성능이 GPT-5.5에 약간 못 미치더라도, 비용이 1/7 수준이라면 동일 예산으로 7배 더 많은 추론이 가능하다. 단, 코딩 보조, 문서 분류, 고객 응대 자동화 등 태스크별로 실제 성능 테스트를 선행하는 것이 필수다. Terminal-Bench 2.0처럼 특정 영역에서는 성능 격차가 크기 때문이다.

**스타트업·개인 개발자**

API 호출 비용에 민감한 팀이라면 DeepSeek-V4-Flash를 1차 검토하는 것이 합리적이다. 합산 $0.42로, 웬만한 프로토타이핑이나 1차 자동화 파이프라인에 충분하다. 성능이 부족하다 느껴질 때 V4-Pro로 업그레이드하는 단계적 접근이 가능하다.

**최고 수준의 정확도가 필요한 태스크**

GPQA Diamond, Humanity's Last Exam 등 고난도 추론 벤치마크에서 Claude Opus 4.7이 여전히 앞선다. 의료, 법률, 고급 과학 연구 등 정확도가 비용보다 우선인 영역에서는 아직 폐쇄형 프리미엄 모델이 우위에 있다. BrowseComp처럼 특정 태스크에서 DeepSeek-V4가 Opus 4.7을 앞서는 경우도 있으므로, 사용 케이스에 맞는 벤치마크 확인이 중요하다.

**자체 인프라가 있는 대기업·연구기관**

MIT 라이선스 오픈소스 가중치를 직접 배포할 수 있는 환경이라면 API 비용 자체를 없앨 수 있다. 1.6조 파라미터 MoE 모델 구동에 필요한 GPU 인프라 투자 비용과 API 누적 비용을 비교해 손익분기점을 계산해볼 만하다.

## 더 저렴하게 쓰는 꿀팁 (연간 구독, 할인 코드 등)

현재 공식 발표 기준으로 DeepSeek API에 대한 연간 구독 할인이나 공식 프로모션 코드는 확인되지 않는다. 다만 다음과 같은 비용 최적화 방법은 구조적으로 적용 가능하다.

**캐시 히트 활용**

DeepSeek-V4-Pro의 캐시 히트 입력 가격은 $0.145로, 캐시 미스 $1.74 대비 약 **91.7% 저렴**하다. 동일한 시스템 프롬프트나 긴 문서를 반복적으로 참조하는 RAG(검색 증강 생성) 파이프라인이라면 캐시를 적극적으로 활용하는 아키텍처 설계가 중요하다. 같은 입력을 반복 전송하는 구조로만 바꿔도 비용이 대폭 줄어든다.

**Flash와 Pro 혼합 사용**

모든 요청에 Pro를 쓸 필요는 없다. 초안 생성, 분류, 요약 등 상대적으로 단순한 태스크에 Flash를 쓰고, 최종 검토나 복잡한 추론에만 Pro를 할당하는 계층형 파이프라인을 구성하면 전체 비용을 크게 낮출 수 있다. Flash는 Pro 대비 입력 기준 약 **92% 저렴**하다.

**오픈소스 자체 배포**

반복적이고 예측 가능한 워크로드를 가진 팀이라면 Hugging Face에 공개된 가중치를 자체 인프라에 올리는 방안을 검토할 수 있다. MIT 라이선스이므로 상업적 배포에 별도 로열티가 없다. GPU 클라우드 비용과 API 누적 비용을 월 단위로 비교해보는 것이 출발점이다.

**토큰 수 최적화**

입출력 토큰 가격이 분리되어 있는 구조상, 출력 토큰이 더 비싸다. 불필요하게 긴 출력을 유도하는 프롬프트 방식을 피하고, 필요한 정보만 간결하게 생성하도록 프롬프트를 설계하면 출력 토큰 비용을 줄일 수 있다.

## 정리하며

DeepSeek-V4의 등장은 "고성능 AI는 비싸다"는 전제를 흔들고 있다. GPT-5.5나 Claude Opus 4.7과 동일한 수준의 성능은 아직 아니다. 벤치마크 수치가 이를 명확하게 보여준다. 하지만 대부분의 실용적 태스크에서 "충분한" 성능을 1/6~1/7 가격에 제공한다는 점은 기업 의사결정에 실질적인 영향을 준다.

VentureBeat의 표현처럼, 이 출시는 "인텔리전스를 무료로 만들지는 않지만, 프리미엄 공급자들이 성능만으로 방어하기 어렵게 만든다." 한국 개발자·기업도 지금이 AI API 공급자 포트폴리오를 재검토할 시점이다.
