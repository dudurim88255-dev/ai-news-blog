# [ChatGPT](https://chat.openai.com) Images 2.0 공개: 한국어 포함 다국어 텍스트, 인포그래픽, 지도, 심지어 만화까지

AI 이미지 생성 시장이 다시 한번 요동치고 있다. OpenAI가 2026년 4월 21일 **ChatGPT Images 2.0**을 공식 발표하면서, 이미지 생성 AI가 단순한 그림 그리기 도구를 넘어 '시각적 추론 엔진'으로 진화하고 있다는 점이 명확해졌다. 텍스트가 포함된 인포그래픽, 프레젠테이션 슬라이드, 지도, 캐릭터 시트, 심지어 만화 형식까지 생성 가능하다는 점에서, 이 업데이트는 단순 품질 개선이 아니라 사용 범위 자체를 다시 정의하는 변화다. 한국 사용자 입장에서는 특히 **다국어 텍스트 지원**, 즉 한국어가 이미지 안에 정확하게 렌더링되는지 여부가 핵심 관심사다.

---

## 무슨 일이 일어난 건가? (30초 요약)

OpenAI는 2026년 4월 21일, ChatGPT의 이미지 생성 기능을 전면 개편한 **ChatGPT Images 2.0**을 공식 출시했다. 공식 발표에 따르면, 이 업데이트는 **모든 ChatGPT 사용자 티어**에 순차적으로 적용된다.

주요 변경 사항을 정리하면 다음과 같다.

- 기존 기본 모델인 **GPT-Image-1.5는 deprecated(단계적 지원 종료)** 처리되며, Images 2.0이 기본 모델로 전환
- API 사용자에게는 **`gpt-image-2`** 모델명으로 제공
- GPT-Image-1.5는 일정 기간 레거시 지원 용도로 API에서 계속 사용 가능

이번 모델은 공개 전에 이미 수주 동안 **LM Arena AI**라는 서드파티 테스트 플랫폼에서 "duct tape"라는 코드명으로 운영됐고, 일부 얼리 테스터들이 그 성능에 상당한 반응을 보였던 것으로 알려졌다. OpenAI는 공개 전 VentureBeat에 벤치마크 수치를 별도로 제공하지 않았다.

## 핵심 내용 정리

### 1. 추론 기반 이미지 생성: "Thinking" 모드

기존 이미지 생성 모델은 프롬프트를 입력하면 바로 이미지를 출력하는 구조였다. ChatGPT Images 2.0은 여기서 벗어나, OpenAI의 **O시리즈 추론 모델 기술**을 이미지 생성에 통합했다.

공식 발표에 따르면, ChatGPT 구독자가 "Thinking" 모드를 선택하면 시스템은 단순히 이미지를 그리는 것이 아니라 **웹 검색, 구조 계획, 추론 과정을 거친 후** 첫 픽셀을 렌더링한다. 이를 OpenAI는 "에이전틱(agentic) 접근 방식"이라고 설명했다.

실제 시연에서 OpenAI의 ChatGPT Images 담당 프로덕트 리드 Adele Li는 내부 제품 전략을 담은 복잡한 PowerPoint 파일을 업로드했고, 모델은 해당 문서의 핵심 데이터를 합성하고 적절한 로고를 찾아 원본 파일의 스타일 요소를 유지한 전문가 수준의 포스터를 생성했다.

Research Lead Boyuan Chen은 모델 아키텍처가 "처음부터 다시 설계됐다(revamped from scratch)"고 밝혔다. 다만 전통적인 diffusion 방식인지 auto-regressive 방식인지는 확인을 거부했고, "이미지를 위한 GPT"에 가까운 **제너럴리스트 모델**로 3D 스타일의 원근법 전환과 복잡한 공간 추론이 텍스트 프롬프트만으로 가능하다고 설명했다.

### 2. 지식 컷오프: 2025년 12월

이번 모델의 학습 데이터 기준일은 **2025년 12월**로, 이전 모델들이 현대적인 맥락을 처리하는 데 어려움을 겪었던 것에 비해 크게 향상됐다. 실시간 웹 검색과 결합해 현재 이벤트나 최신 기술 정보를 이미지에 반영하는 것이 가능하다고 공식 발표는 명시하고 있다.

### 3. 다국어 텍스트 및 복합 시각물 생성

공식 발표와 VentureBeat의 테스트에 따르면, 이번 모델이 처리할 수 있는 시각 콘텐츠의 범위는 다음과 같다.

- 이미지 내 **긴 텍스트 블록** 및 **복수의 텍스트 패널** 생성
- **다국어 텍스트** 포함 이미지 (공식 발표에서 "multilingual text" 명시)
- **인포그래픽**, 프레젠테이션 슬라이드 형식
- **지도** (아즈텍·마야·잉카 제국 영역 지도와 완전히 판독 가능한 범례를 정확하게 생성했다고 VentureBeat 기자가 직접 테스트해 확인)
- **도면(floor plan)**
- **이미지 그리드** 및 복수의 소형 이미지 묶음
- **다각도 캐릭터 모델**
- 인기 웹사이트·플랫폼의 UI 및 스크린샷 재현
- **만화(manga) 형식**
- 실존 인물(예: Sam Altman) 재현
- 사용자 업로드 이미지에 위 대부분의 기능 적용 가능

한국어를 포함한 다국어 지원이 공식적으로 언급된 것은 국내 사용자에게 주목할 만한 지점이다. 다만 VentureBeat 원문에는 한국어 단독 테스트 결과는 포함되어 있지 않으므로, 실제 한국어 텍스트 품질은 직접 확인이 필요한 상태다.

### 4. GPT-Image-1.5와의 관계

2025년 12월 출시됐던 GPT-Image-1.5는 지시 따르기, 색감, 조명 개선을 가져온 모델이었다. 이번 Images 2.0 출시와 함께 기본 모델 지위를 잃고 deprecated 처리된다. API에서는 레거시 지원 목적으로 계속 사용 가능하다.

## 왜 중요한가? (일반인에게 미치는 영향)

이미지 생성 AI는 지금까지 주로 "그림을 그려주는 도구"로 인식되어 왔다. 정확한 텍스트를 이미지 안에 넣는 것조차 대부분의 모델이 오랫동안 해결하지 못한 과제였다.

ChatGPT Images 2.0은 이 한계를 정면 돌파하는 방향을 택했다. 인포그래픽, 슬라이드, 지도처럼 **텍스트와 시각 정보가 결합된 콘텐츠**는 기업 커뮤니케이션, 교육 자료, 마케팅 소재에서 매일 사용되는 형식이다.

이 기능이 실제로 작동한다면, 현재 이런 자료를 만들기 위해 디자이너나 별도의 디자인 툴(Canva, PowerPoint, Adobe 등)에 의존하는 업무 흐름이 달라질 수 있다. 물론 전문 디자인 작업을 완전히 대체할 수 있을지는 아직 검증이 필요한 단계다.

또한 웹 검색을 결합한 실시간 정보 반영은 "최신 데이터를 기반으로 한 시각 자료 자동 생성"이라는 시나리오를 현실로 가져온다. 예를 들어 특정 주제의 최신 통계를 가져와 차트나 인포그래픽으로 자동 변환하는 방식이 가능해질 수 있다.

## 업계 반응 & 전문가 시각

### 구글과의 경쟁 구도

VentureBeat 원문은 2026년 2월 Google이 **Nano Banana 2**([Gemini](https://gemini.google.com) 3 Pro Image 또는 Gemini 3.1 Pro Image로도 알려진)를 출시하면서 AI 이미지 생성 시장의 경쟁이 심화됐다고 지적한다. Google의 모델도 텍스트가 이미지에 내장된 형식을 지원하는 유사한 기능을 제공한다.

VentureBeat 기자는 자신의 간단한 테스트와 다른 사용자들의 이미지 사례를 토대로, ChatGPT Images 2.0이 UI 재현, 스크린샷 생성, 복수 이미지 묶음 생성에서 Google의 최신 모델을 앞서는 것으로 보인다고 밝혔다. 그러나 이는 공식 벤치마크가 아닌 **개인 테스트 및 관찰에 기반한 평가**임을 명확히 해두었다. 검증된 벤치마크는 현재 공개되지 않은 상태다.

### AI 생성 이미지의 오용 우려

VentureBeat는 최근 뉴욕타임스 보도를 인용하며, AI 사용자 생성 콘텐츠(AI UGC)가 현실적인 AI 영상의 씨앗으로 활용되어 소셜미디어에 대량 유포되는 정치적 영향력 공작에 사용되고 있다는 우려를 제기했다.

이에 대해 OpenAI 측은 다음과 같이 입장을 밝혔다. Adele Li는 공식 브리핑에서 "안전과 보안을 매우 진지하게 다루고 있으며, 정치적 또는 선거 개입과 관련된 모든 사항이 여기에 포함된다"고 말했다. 또한 "ChatGPT는 다른 플랫폼과 달리 이러한 안전장치를 갖추고 있으며, AI 생성 이미지에 메타데이터를 태깅하는 방식으로 생성물을 식별할 수 있게 하는 조치를 이어가고 있다"고 덧붙였다.

다만 이러한 안전장치가 실제로 얼마나 효과적인지는 원문에서도 별도로 검증된 바 없다.

## 앞으로 어떻게 될까? (단기/장기 전망)

### 단기 전망

- ChatGPT Images 2.0은 현재 모든 ChatGPT 사용자 티어에 롤아웃 중이다. 구체적인 국가별 출시 일정이나 기능 순차 제공 계획은 원문에 공개되지 않았다.
- API 사용자는 `gpt-image-2` 모델로 접근할 수 있으며, GPT-Image-1.5는 레거시 용도로 병행 사용 가능하다.
- "Thinking" 모드는 ChatGPT 구독자를 대상으로 제공되는 것으로 발표됐다.

### 장기 전망

이미지 생성 AI가 추론 기능을 탑재하는 방향으로 발전하면, 단순 생성 도구에서 **작업 자동화 에이전트**에 가까운 위치로 이동하게 된다. 문서를 분석해 시각 자료를 만들고, 최신 웹 정보를 가져와 인포그래픽으로 출력하는 파이프라인이 일반화될 경우, 콘텐츠 제작·교육·마케팅 분야에서 작업 방식에 변화가 생길 수 있다.

다만 Google, [Midjourney](https://www.midjourney.com), Adobe Firefly 등 경쟁 플랫폼들도 빠른 속도로 유사한 방향을 추구하고 있어, 이 분야의 경쟁 구도가 앞으로도 계속 변화할 것으로 보인다.

## 한국 사용자에게 미치는 영향

현재 ChatGPT는 한국에서 정식 서비스되고 있으며, 이번 Images 2.0 역시 별도의 지역 제한이 공지되지 않았다면 한국 사용자도 접근할 수 있을 것으로 보인다. 다만 공식 발표에서 국가별 출시 일정은 명시되지 않았다.

가격 관련해서는, ChatGPT Plus 구독료는 현재 월 20달러(약 2만 7천~2만 8천 원 수준, 환율에 따라 변동)이며 "Thinking" 모드는 구독자를 대상으로 한다고 발표됐다. API 가격(`gpt-image-2` 기준)은 공식 발표에서 공개되지 않았다.

**한국어 텍스트 렌더링** 지원은 공식 발표에서 "multilingual text"로 명시됐다. 한국어가 포함되는지 공식 문서에서 명확히 특정하진 않았지만, 다국어 지원 범위에 포함될 가능성이 있다. 실제 한국어 텍스트 포함 이미지의 품질은 직접 테스트를 통해 확인이 필요하다.

한국 사용자 입장에서 특히 주목할 시나리오는 다음과 같다.

- **카드뉴스·인포그래픽 제작**: 한국어가 정확하게 렌더링된다면 SNS용 카드뉴스, 교육 콘텐츠 제작 워크플로우에 변화가 생길 수 있다.
- **프레젠테이션 보조**: PowerPoint 파일을 업로드해 시각 자료를 자동 생성하는 기능은 기업 및 교육 환경에서 활용 가능성이 있다.
- **웹툰·만화 형식 지원**: 만화 형식 생성이 언급된 점은 웹툰 산업이 강한 한국 시장에서 창작 도구로서의 가능성을 열어두는 지점이다.

다만 어떤 기능이 실제 한국어 환경에서 얼마나 자연스럽게 작동하는지는 현 시점에서 충분히 검증된 데이터가 없다. 공식 발표 이후 사용자들의 실제 테스트 사례가 축적되어야 더 정확한 평가가 가능할 것이다.

---

ChatGPT Images 2.0은 이미지 생성의 문법을 다시 쓰려는 시도다. 단순히 더 예쁜 그림을 만드는 것이 아니라, 생각하고 조사하고 구조화한 뒤 시각적으로 표현하는 과정 전체를 AI가 처리하는 방향으로 나아가고 있다. OpenAI 공식 발표에서 밝힌 "이미지는 장식이 아니라 언어다(Images are a language, not decoration)"라는 문장이 이번 업데이트의 방향을 가장 잘 요약한다.

기능의 실제 완성도는 더 많은 사용자 테스트가 필요하지만, 추론 기반 이미지 생성이라는 접근 방식 자체는 이 분야의 다음 경쟁 구도를 바꾸는 기준점이 될 가능성이 있다.
