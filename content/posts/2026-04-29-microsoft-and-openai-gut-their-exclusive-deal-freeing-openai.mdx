# Microsoft-OpenAI 독점 계약 해체: AWS·구글 클라우드에서도 OpenAI 쓸 수 있게 된다

2026년 4월 28일, AI 업계에서 가장 중요한 파트너십 구조가 근본적으로 바뀌었다. Microsoft와 OpenAI가 수년간 유지해온 독점 계약을 대폭 수정하면서, OpenAI 모델이 이제 AWS와 Google Cloud를 통해서도 제공될 수 있게 됐다. 한국의 기업 사용자와 개발자 입장에서는 단순한 외국 기업들 간의 계약 변경처럼 보일 수 있다. 하지만 이 결정은 국내 클라우드 도입 전략, AI API 비용 구조, 그리고 어느 플랫폼에서 OpenAI 서비스를 써야 하는지에 직접적인 영향을 미친다. 지금 이 뉴스가 중요한 이유가 바로 여기 있다.

---

## 계약 변경 내용 한눈에 보기

공식 발표에 따르면 이번 계약 수정의 핵심 내용은 크게 네 가지다.

**첫째, Azure 수익 배분 종료.** 지금까지 Microsoft는 고객이 Azure를 통해 OpenAI 모델에 접근할 때 OpenAI에 수익 일부를 지불해왔다. 새 계약에서는 이 조항이 삭제됐다. Microsoft 입장에서는 Azure를 통한 OpenAI 모델 판매 수익을 온전히 가져갈 수 있게 된 셈이다.

**둘째, OpenAI의 수익 배분 의무 유지, 단 한도 설정.** OpenAI는 2030년까지 Microsoft에 수익의 20%를 계속 지불한다. 다만 이전과 달리 총 지불 한도(cap)가 설정됐다. 구체적인 한도 금액은 공개되지 않았다.

**셋째, Microsoft의 IP 라이선스 비독점으로 전환.** Microsoft는 2032년까지 OpenAI의 지식재산(모델 및 제품)에 대한 라이선스를 유지한다. 단, 이 라이선스는 이제 명시적으로 비독점(non-exclusive)으로 변경됐다.

**넷째, OpenAI의 멀티클라우드 판매 허용.** 가장 핵심적인 변화다. OpenAI는 이제 AWS, Google Cloud를 포함한 모든 클라우드 제공업체에 자사 제품을 제공할 수 있다. 기존 계약의 가장 강력한 독점 조항이 사라진 것이다.

---

## 무료 플랜으로 실제로 뭘 할 수 있나?

이번 계약 변경은 일반 소비자용 [ChatGPT](https://chat.openai.com) 무료 플랜에 즉각적인 영향을 주지는 않는다. ChatGPT 무료 사용자는 여전히 OpenAI 직접 서비스를 통해 GPT 계열 모델에 접근하며, 이 접근 경로는 이번 계약 수정과 별개로 유지된다.

그러나 개발자와 기업 사용자에게는 의미가 다르다. 지금까지 OpenAI API를 사용하려는 기업은 Azure 클라우드 환경에서 접근하거나 OpenAI 직접 API를 사용하는 두 가지 경로만 있었다. 이번 변경 이후에는 AWS Bedrock이나 Google Cloud Vertex AI를 이미 기본 인프라로 쓰는 기업이 해당 환경 안에서 OpenAI 모델을 통합할 수 있는 가능성이 열렸다.

특히 원문에 언급된 OpenAI의 엔터프라이즈 에이전트 빌딩 플랫폼 'Frontier'가 AWS에서도 제공될 예정이다. 다만 이 서비스는 발표만 된 상태로, 국내 출시 일정은 공개되지 않았다.

---

## 유료 플랜, 돈 값 하나? (원화 환산 포함)

현재 이번 계약 변경으로 인해 OpenAI API의 요금이 바뀐다는 공식 발표는 없다. 따라서 기존 요금 체계를 기준으로 설명한다.

OpenAI API를 Azure를 통해 사용하는 경우와 OpenAI 직접 API를 사용하는 경우, 요금 차이가 발생할 수 있다. Azure OpenAI Service는 Microsoft의 인프라 비용 및 서비스 레이어가 추가되는 구조이며, 요금은 공개된 Azure 가격표를 기준으로 각 기업이 협의를 통해 결정하는 경우도 있다.

앞으로 AWS Bedrock이나 Google Cloud를 통해 OpenAI 모델이 제공될 경우, 각 클라우드 플랫폼의 마진 구조에 따라 요금이 달라질 수 있다. 구체적인 요금은 현재 공개되지 않은 상태다.

원화 환산 측면에서, 현재 OpenAI API GPT-4o 기준 입력 토큰 100만 개당 $2.50, 출력 토큰 100만 개당 $10.00가 직접 API 기준 공개 가격이다(OpenAI 공식 사이트 기준, 2025년 발표 기준). 환율 1,400원 적용 시 입력 100만 토큰당 약 3,500원, 출력 100만 토큰당 약 14,000원 수준이다. 단, 이 수치는 현재 공개된 요금을 참고한 것이며, AWS·Google Cloud 경유 시 요금은 별도 공개될 예정이다.

한국어 지원 여부와 관련해서는, OpenAI 모델 자체의 한국어 처리 능력은 AWS나 Google Cloud를 통해 접근하더라도 동일한 모델이 사용되는 구조이므로 큰 차이가 없을 것으로 예상된다. 단, 각 클라우드 플랫폼의 관리 콘솔, 지원 체계, 결제 환경 등은 플랫폼별로 다르다.

## 경쟁 서비스와 가격 비교

이번 계약 변경의 배경을 이해하려면 경쟁 구도를 먼저 봐야 한다. 원문에 따르면 OpenAI의 수익 책임자 Denise Dresser는 내부 메모에서 Microsoft 파트너십이 "기업 고객이 있는 곳에서 만나는 능력을 제한했다"고 직접적으로 밝혔다. 즉, 기업들이 AWS나 Google Cloud를 기본 인프라로 쓰고 있는데 OpenAI만 Azure로 이전하라는 것은 현실적인 장벽이었다는 뜻이다.

현재 AWS Bedrock에서는 Anthropic의 [Claude](https://claude.ai) 모델, Meta의 Llama, Mistral 등 다양한 모델을 이미 제공하고 있다. Google Cloud Vertex AI에서는 [Gemini](https://gemini.google.com) 모델 계열이 기본으로 제공된다. OpenAI가 이 플랫폼들에 합류하게 되면, 기업 사용자는 단일 클라우드 환경에서 여러 AI 모델을 비교하고 선택할 수 있는 구조가 된다.

구체적인 벤치마크 기반의 성능 비교는 이번 계약 내용과 직접 관계가 없으며, 현재 AWS·Google Cloud에서의 OpenAI 모델 요금이 공개되지 않은 상황이므로 직접적인 가격 비교는 이 단계에서 불가능하다.

---

## 어떤 클라우드를 선택해야 할까? (상황별 추천)

이번 계약 변경 이후 실제 선택 기준이 어떻게 달라지는지를 상황별로 살펴보자.

**이미 AWS를 주 인프라로 쓰는 기업:** OpenAI의 Frontier 플랫폼이 AWS에서 제공되면, 별도로 Azure 계정을 개설하거나 이중 인프라를 유지하지 않고도 OpenAI 기반 에이전트를 구축할 수 있다. 특히 AWS와의 계약에서 $100 billion(약 140조 원) 규모의 8년 클라우드 계약이 체결된 만큼, AWS 측의 OpenAI 모델 지원은 장기적으로 안정적으로 유지될 가능성이 높다고 원문은 설명한다.

**Azure를 이미 쓰고 있는 Microsoft 생태계 기업:** 현재 구조에서 Azure를 통한 OpenAI 접근은 계속 유지된다. Microsoft의 IP 라이선스는 2032년까지 보장돼 있으므로, Azure OpenAI Service의 서비스 지속성은 당분간 문제가 없다.

**Google Cloud 기반 기업:** Google Cloud를 통한 OpenAI 제공은 현재 발표된 내용에서 구체적인 일정이 명시되지 않았다. 이 부분은 추후 별도 발표가 있을 것으로 예상된다.

**스타트업 및 개인 개발자:** OpenAI 직접 API를 사용하는 경우 이번 계약 변경의 직접적인 영향은 크지 않다. 다만 멀티클라우드 경쟁이 심화될수록 장기적으로 요금 경쟁이 발생할 가능성도 있다. 이는 현재로서는 가능성의 영역이지, 확정된 내용이 아니다.

## 이번 계약 해체가 만들어진 배경: $50억 달러의 Amazon 투자

원문에 따르면 이번 구조 변경의 직접적인 원인은 철학적 논쟁이 아니었다. 아마존의 투자였다.

2026년 2월, OpenAI는 Amazon이 최대 $50 billion(약 70조 원)을 투자한다고 발표했다. 우선 $15 billion(약 21조 원)을 선투자하고, 특정 조건 충족 시 추가 $35 billion(약 49조 원)을 투입하는 구조였다. 이와 함께 OpenAI는 AWS와 8년간 $100 billion(약 140조 원) 규모의 클라우드 계약을 확대하고, Frontier 플랫폼의 독점 제3자 배포 제공자로 AWS를 지정하기로 합의했다.

문제는 이 발표가 OpenAI의 기존 Microsoft 계약을 명백히 위반할 가능성이 컸다는 점이다. 원문에 따르면 Financial Times는 Microsoft가 계약상 권리를 집행하기 위한 법적 조치를 검토 중이었다고 보도했다. OpenAI는 Amazon에는 약속을 했지만 Microsoft 계약상으로는 이를 이행할 수 없는 상황에 놓였다.

이번 4월의 계약 수정은 사실상 이 법적 위기를 협상으로 해결한 결과물이다.

## 더 저렴하게 OpenAI를 쓰는 방법 (현실적 조언)

현재 시점에서 AWS나 Google Cloud를 통한 OpenAI 모델 접근은 아직 서비스 개시 전이다. 따라서 지금 당장 활용할 수 있는 방법은 제한적이다. 그러나 이번 변화를 앞두고 미리 준비할 수 있는 현실적인 접근은 다음과 같다.

**클라우드 약정 크레딧 활용:** AWS, Azure, Google Cloud 모두 선약정 할인 또는 신규 가입 크레딧을 제공한다. OpenAI 모델이 여러 플랫폼에서 제공될 경우, 각 플랫폼의 크레딧을 활용해 초기 비용을 줄일 수 있다. 구체적인 크레딧 금액은 각 클라우드 공식 사이트를 통해 확인해야 한다.

**멀티클라우드 전략 재검토:** 이번 계약 변경 이후 OpenAI API가 여러 클라우드에서 제공되면, 기업 입장에서는 자사의 기존 클라우드 약정 조건에 따라 어느 경로가 더 경제적인지 비교하는 것이 가능해진다. 단, 현재로서는 각 플랫폼별 요금이 공개되지 않았으므로 실제 비교는 서비스 출시 후에 가능하다.

**직접 API 활용 유지:** 현재 OpenAI 직접 API는 멀티클라우드 옵션이 생기더라도 계속 사용할 수 있다. 클라우드 종속성 없이 유연하게 사용하려는 경우 직접 API가 여전히 유효한 선택지다.

**Tier 기반 할인 구조 확인:** OpenAI API는 사용량에 따라 요금 등급이 나뉜다. 사용량이 늘수록 더 낮은 단가가 적용될 수 있으므로, 팀 내 API 사용을 통합해 관리하는 것이 비용 효율 측면에서 유리하다.

## 정리: 이 변화가 한국 기업과 개발자에게 의미하는 것

공식 발표에 따르면, Microsoft-OpenAI의 독점 계약 해체는 단순한 두 기업 간의 내부 조율이 아니다. 생성형 AI 산업의 유통 구조 자체가 바뀌는 사건이다.

국내 기업 중 Azure를 메인 클라우드로 사용해온 곳은 기존 서비스 연속성이 보장된다. AWS나 Google Cloud를 쓰는 국내 기업은 조만간 자사 환경에서 OpenAI 모델을 직접 통합할 수 있는 옵션을 얻게 된다. 이는 클라우드 전환 없이도 OpenAI 기반 서비스를 구축할 수 있다는 의미다.

한국어 지원이나 국내 데이터 센터 기반 서비스 여부 등 구체적인 사항은 아직 발표되지 않았다. 각 클라우드 플랫폼의 한국 리전에서 OpenAI 모델 서비스가 어떻게 제공될지는 추후 공개될 정보를 기다려야 한다.

2026년 AI 인프라 경쟁의 핵심 축이 이번 계약 변경을 통해 다시 그려지고 있다. 기업과 개발자 모두 자사의 클라우드 전략을 지금 시점에서 점검해볼 필요가 있다.
